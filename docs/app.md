# 📱 安心云 App

> 一句话：因为"复制链接、找配置、手动导入"太麻烦，我们做了个 App。**Android 版已发布（v1.1.0），iOS 在规划中。**

---

## 为什么做 App

用订阅链接 + 第三方客户端（v2rayNG / Clash Verge）这套方式，对技术用户没问题，对普通用户有三道坎：

1. 要去应用商店找客户端、分辨哪个是正版；
2. 要从网页复制一长串订阅地址，粘到客户端里；
3. 想换地区时，得回到客户端里翻节点列表，几十个名字看花眼。

App 把这三步合成一步：**登录 → 点连接**。

## App 里有什么

| 功能 | 说明 |
|---|---|
| 🔘 一键连接 | 首页一个大按钮，点一下就连上，不用碰任何配置 |
| 🌍 地区切换 | 10 个地区列表直接点选，显示的是地区名而不是节点域名 |
| 📥 订阅自动下发 | 登录后自动获取订阅，换设备不用重新折腾 |
| 📊 状态显示 | 当前地区、连接时长、本次用量 |
| 🔐 账户管理 | 登录、退出、查看套餐与到期时间 |

App 内部使用标准协议（VLESS + WebSocket + TLS 1.3）与官方节点，与订阅链接走同一套后端——**不是另一套"App 专用"的线路**。

## 不用 App 也完全没问题

App 是"少折腾"的可选项，不是必需品。标准订阅链接支持这些客户端：

| 平台 | 推荐客户端 | 导入方式 |
|---|---|---|
| Android | v2rayNG | 一键导入（`v2rayng://install-sub?url=`） |
| Windows / macOS / Linux | Clash Verge Rev | 一键导入（`clash://install-config?url=`） |
| iOS | Shadowrocket 等 | 手动复制订阅链接添加 |

换设备时订阅地址**默认复用**，不用重新获取；除非你在控制台主动"重置订阅链接"（重置后旧地址立即失效，所有设备都要重新导入）。

## 常见问题

**App 收费吗？**
App 本身完全免费，使用需要有效订阅或试用（与网页端同一份账户与权益）。

**App 和第三方客户端哪个快？**
走的是同一批节点、同一套协议，速度没有差别。区别只在操作便利性。

**为什么 iOS 还没有？**
iOS 的网络扩展开发需要 macOS 设备、Xcode 和 Apple 开发者账号，且审核更严。我们在 Android 稳定后启动。

**App 会读取我的其他数据吗？**
不会。App 只申请建立 VPN 连接所需的系统权限，不读取联系人、位置、相册等无关信息。

**遇到问题怎么办？**
先更新到最新版本；仍不行就把手机型号、Android 版本和现象发给我们。我们会尽快修。
