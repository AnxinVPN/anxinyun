# 订阅链接为什么是一份"凭据"

## 为什么订阅链接要特别对待？

- 订阅链接包含你的唯一身份信息（token），任何人拿到链接即可使用你的权益
- 因此系统默认**复用**（换设备不用重置）
- 显式选择"重置"才会签发新地址并使旧地址立即失效

## 用户侧行为建议

- 设备多时可以让同一账户下的多个设备各自导入同一个订阅链接（不同设备走各自的设备额度）
- 换设备时无需重置链接（系统已支持默认复用）
- 必须时才重置（显式点击重置后旧地址立即失效）

## 安全提醒

- 订阅地址属于账户凭据，请勿公开分享
- 重置后旧地址立即失效，旧链接无法再使用
