## 安全特性（事实来源）

- **节点零日志**：节点不存储使用日志，上网行为不留记录
- **TLS 1.3 隧道加密**：全程加密传输，保护设备到服务入口之间的链路
- **注册只要邮箱**：无需真实姓名或手机号
- **8 个地区 · 40 个节点入口**：逻辑节点入口，不等于 40 台独立服务器或 40 个独立 IP
- **设备额度**：授权设备额度（个人版 3 台 / 多设备版 5 台；设备登记数不代表同时在线数）
- **60 分钟免费试用**：邮箱验证后领取一次，无需绑定支付方式
